# Микола Сом. Поезія і проза

Статичний сайт із творами Миколи Сома. Зібраний на [Astro](https://astro.build), публікується на GitHub Pages.

## Запуск на своєму комп'ютері

Потрібен Node.js 22.22 або новіший.

```bash
npm install          # один раз
npm run dev          # сайт із живим оновленням: http://localhost:4321/mykola-som/
npm run build        # зібрати сайт у dist/ (разом з пошуковим індексом)
npm run preview      # переглянути зібраний сайт; пошук працює лише тут
```

## Де лежать тексти

Кожна книга — окрема папка в `src/content/knyhy/`:

```
src/content/knyhy/
└─ vybrane/                 ← назва папки = адреса книги: /knyhy/vybrane/
   ├─ book.yaml             ← опис книги
   └─ somova-vulytsia.md    ← один файл = один твір: /knyhy/vybrane/somova-vulytsia/
```

### book.yaml

```yaml
title: Вибране
kind: poetry          # poetry — поезія, prose — проза, mixed — поезія і проза
order: 1              # порядок на головній сторінці
year: 1995            # необов'язково
subtitle: …           # необов'язково
description: …        # необов'язково, короткий опис під назвою
cover: ./cover.jpg    # необов'язково, обкладинка поруч із book.yaml
draft: true           # необов'язково: книгу видно лише в npm run dev
```

### Файл твору

```markdown
---
title: "Назва"
order: 12                  # місце у змісті книги
subtitle: "Байка"          # необов'язково
dedication: "Павлові Загребельному"
epigraph: "Перший рядок епіграфа\nДругий рядок"
epigraphSource: "З народної пісні"
date: 1967                 # необов'язково, підпис під твором разом із place
place: "Київ"
note: "* Примітка під твором."
author: "Олесь Жолдак"     # лише якщо автор не Микола Сом (передмова тощо)
untitled: true             # вірш без назви: на сторінці «* * *», у змісті — title
kind: prose                # лише якщо вид тексту відрізняється від виду книги
section: "Епітафії"        # розділ книги: зміст групується за розділами
epigraphs: [{"text": "…", "source": "…"}, {"text": "…"}]   # кілька епіграфів замість epigraph
---

Текст твору.
```

**Вірш** записується як звичайний текст, без Markdown:

- кожен рядок вірша — окремий рядок файлу;
- порожній рядок розділяє строфи;
- пробіли на початку рядка зберігаються (так робиться «драбинка»);
- `* * *` окремим рядком — розділювач частин;
- `## 2` або `## Назва` — підзаголовок частини чи вірша в циклі, `### Байка` — підпис під ним.

**Проза** записується як Markdown: абзаци розділяє порожній рядок, `*курсив*`, `## Підзаголовок`, `***` — розділювач сцен. Цитату чи вставку вірша всередині прози беріть у блок:

````markdown
```verse
Пісню візьму в народу,
Дам і народу пісню.
```
````

### Як додати твір

Створіть новий `.md` у папці книги (назва файлу латиницею — вона стане адресою) і вкажіть `order`.

### Як додати книгу

Створіть папку `src/content/knyhy/<назва-латиницею>/` з `book.yaml` і текстами. Як зразок можна взяти демонстраційну книгу прози `zrazok-prozy` (вона позначена `draft: true` і на сайт не потрапляє).

### Імпорт з Word

Скрипт розбирає .docx на окремі твори (назви ВЕЛИКИМИ ЛІТЕРАМИ, посвяти, епіграфи, цикли, примітки, передмову як прозу):

```bash
npm run import-docx -- --book <назва-латиницею> _source/<файл>.docx --dry-run   # лише звіт
npm run import-docx -- --book <назва-латиницею> _source/<файл>.docx             # запис
```

### Книга зі сканів (PDF без тексту)

Так додано «Передай кодолу!»: сторінки скану розпізнаються в окремі файли
`_source/<книга>/pages/NNN.md` за правилами `_source/<книга>/INSTRUCTIONS.md`, а потім складаються в книгу:

```bash
node scripts/assemble-pages.mjs --book <назва-латиницею> --dry-run   # звіт: твори за розділами, звірка зі змістом книги
node scripts/assemble-pages.mjs --book <назва-латиницею> --force     # запис
```

Назви творів беруться зі змісту книги, налаштування (назва, рік, виправлення сумнівних слів) — у `scripts/import/<книга>.json`.

Оригінали .docx і PDF кладіть у `_source/` — ця папка не потрапляє в репозиторій. Виправлення регістру назв зберігаються в `scripts/import/<книга>.json`. Після імпорту основним джерелом стають `.md`-файли: правте їх, а повторний імпорт (`--force`) затре ручні правки.

## Пошуковики

- Карта сайту створюється автоматично під час збирання: https://wyrax.github.io/mykola-som/sitemap-index.xml. До неї потрапляють усі опубліковані сторінки, крім пошуку, 404 і чернеток.
- Кожна сторінка має канонічну адресу (`<link rel="canonical">`); сторінка 404 позначена `noindex`.
- `robots.txt` для сайту на `wyrax.github.io/mykola-som/` пошуковики не читають (він мав би лежати в корені домену), тож карту сайту треба надіслати вручну: Google Search Console → ресурс «URL-префікс» `https://wyrax.github.io/mykola-som/` → «Файли Sitemap» → `sitemap-index.xml`. Так само в Bing Webmaster Tools.
- `public/googleec3764e8b6a9dded.html` — файл підтвердження права власності в Google Search Console. Не видаляйте його, інакше Google втратить доступ до ресурсу.
