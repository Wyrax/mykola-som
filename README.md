# Микола Сом. Поезія і проза

Статичний сайт із творами Миколи Сома. Зібраний на [Astro](https://astro.build), публікується на GitHub Pages.

## Запуск на своєму комп'ютері

Потрібен Node.js 22.22 або новіший.

```bash
npm install          # один раз
npm run dev          # сайт із живим оновленням: http://localhost:4321/mykola-som/
npm run build        # зібрати сайт у dist/ (разом з пошуковим індексом)
npm run preview      # переглянути зібраний сайт; пошук працює лише тут
```

## Де лежать тексти

Кожна книга — окрема папка в `src/content/knyhy/`:

```
src/content/knyhy/
└─ vybrane/                 ← назва папки = адреса книги: /knyhy/vybrane/
   ├─ book.yaml             ← опис книги
   └─ somova-vulytsia.md    ← один файл = один твір: /knyhy/vybrane/somova-vulytsia/
```

### book.yaml

```yaml
title: Вибране
kind: poetry          # poetry — поезія, prose — проза, mixed — поезія і проза
year: 1957            # рік видання: на головній книги стоять за роком, книги без року — наприкінці
order: 1              # порядок серед книг того самого року (або серед книг без року)
subtitle: …           # необов'язково
description: …        # необов'язково, короткий опис під назвою
cover: ./cover.jpg    # необов'язково, обкладинка поруч із book.yaml (див. «Обкладинка книги»)
draft: true           # необов'язково: книгу видно лише в npm run dev
```

### Файл твору

```markdown
---
title: "Назва"
order: 12                  # місце у змісті книги
subtitle: "Байка"          # необов'язково
dedication: "Павлові Загребельному"
epigraph: "Перший рядок епіграфа\nДругий рядок"
epigraphSource: "З народної пісні"
date: 1967                 # необов'язково, підпис під твором разом із place
place: "Київ"
note: "* Примітка під твором."
author: "Олесь Жолдак"     # лише якщо автор не Микола Сом (передмова тощо)
untitled: true             # вірш без назви: на сторінці «* * *», у змісті — title
kind: prose                # лише якщо вид тексту відрізняється від виду книги
section: "Епітафії"        # розділ книги: зміст групується за розділами
epigraphs: [{"text": "…", "source": "…"}, {"text": "…"}]   # кілька епіграфів замість epigraph
---

Текст твору.
```

**Вірш** записується як звичайний текст, без Markdown:

- кожен рядок вірша — окремий рядок файлу;
- порожній рядок розділяє строфи;
- пробіли на початку рядка зберігаються (так робиться «драбинка»);
- `* * *` окремим рядком — розділювач частин;
- `## 2` або `## Назва` — підзаголовок частини чи вірша в циклі, `### Байка` — підпис під ним.
- `> текст` окремим рядком — прозовий абзац усередині вірша (довідка, цитата): він стоїть у ширину вірша, дрібнішим шрифтом.

**Проза** записується як Markdown: абзаци розділяє порожній рядок, `*курсив*`, `## Підзаголовок`, `***` — розділювач сцен. Цитату чи вставку вірша всередині прози беріть у блок:

````markdown
```verse
Пісню візьму в народу,
Дам і народу пісню.
```
````

### Як додати твір

Створіть новий `.md` у папці книги (назва файлу латиницею — вона стане адресою) і вкажіть `order`.

### Як додати книгу

Створіть папку `src/content/knyhy/<назва-латиницею>/` з `book.yaml` і текстами. Як зразок можна взяти демонстраційну книгу прози `zrazok-prozy` (вона позначена `draft: true` і на сайт не потрапляє).

### Обкладинка книги

Скан обкладинки (PNG чи JPG будь-якого розміру) кладіть у `_source/` і додавайте командою:

```bash
npm run add-cover -- --book <назва-латиницею> "_source/<файл>.png"
```

Скрипт зменшить зображення, збереже його як `cover.jpg` у папці книги й пропише `cover: ./cover.jpg` у `book.yaml`; повторний запуск замінює обкладинку. Під час збирання сайт сам робить копії потрібних розмірів (AVIF, WebP, JPEG). Обкладинку видно на сторінці книги та в прев’ю посилання в соцмережах. Книга без обкладинки показується там, де потрібна картинка, «типографічною» обкладинкою з автором і назвою.

### Імпорт з Word

Скрипт розбирає .docx на окремі твори (назви ВЕЛИКИМИ ЛІТЕРАМИ, посвяти, епіграфи, цикли, примітки, передмову як прозу):

```bash
npm run import-docx -- --book <назва-латиницею> _source/<файл>.docx --dry-run   # лише звіт
npm run import-docx -- --book <назва-латиницею> _source/<файл>.docx             # запис
```

### Книга зі сканів (PDF без тексту)

Так додано «Передай кодолу!»: сторінки скану розпізнаються в окремі файли
`_source/<книга>/pages/NNN.md` за правилами `_source/<книга>/INSTRUCTIONS.md`, а потім складаються в книгу:

```bash
node scripts/assemble-pages.mjs --book <назва-латиницею> --dry-run   # звіт: твори за розділами, звірка зі змістом книги
node scripts/assemble-pages.mjs --book <назва-латиницею> --force     # запис
```

Назви творів беруться зі змісту книги, налаштування (назва, рік, виправлення сумнівних слів) — у `scripts/import/<книга>.json`. Вірш без назви позначається на сторінці як `## * * *`: у змісті сайту він з’явиться під своїм першим рядком. Сторінки, які не йдуть у текст (обкладинка, титул, вихідні дані), позначаються в службовому рядку словом `службова`. Так само додано «Йду на побачення» (1957), «Святий хліб» (1961), «Дума над вогнем» (1968), «Стежка до океану» (1973), «Б’ю чолом!» (1978), «Мрія» (1980), «Присвяти і послання» (1983), «Моєї радості сльоза» (1990), «Сто епітафій» (1998), «Як я Сталіна хоронив» (2002) і «Придибенції» (2009). З пісенника «Мрія» перенесено лише тексти пісень, надруковані після нот; сторінки з нотами позначено як службові, а текст хорової пісні, якого окремо не надруковано, зібрано зі складів під нотами (сторінка `039a.md`). У скані «Святого хліба» бракує аркуша (с. 26–27) — на місці пропуску в поемі «Марія» стоїть `[…]` (сторінка `026a.md`). Якщо назва над твором надрукована з помилкою, її зводять зі змістом через `tocAliases` (надрукована назва → назва зі змісту), а твір, що стоїть у змісті наприкінці розділу, але до нього не належить (як «Слово про автора»), виносять з розділу через `noSection`. Сторінку, якої немає в скані, можна додати з іншого видання файлом із літерою після номера: `092a.md` стане одразу після `092.md` (так у «Думі над вогнем» з’явилася «Осіння дума» зі збірки «Передай кодолу!»). Повтор уже сканованої сторінки чи сторінку лише з фото позначають у службовому рядку словом `службова`. У книзі прози (`kind: prose` у `scripts/import/<книга>.json`) кожен твір — проза, навіть коротка придибенція з короткими абзацами; орнамент усередині прозового твору записують рядком `***` — на сайті це «* * *». Епіграф одразу під назвою розділу (`# Розділ`, потім блок `[епіграф]`) стає епіграфом розділу: складальник пише його в `book.yaml` (`sectionEpigraphs`), а сторінка книги показує його під назвою розділу в змісті. Твір у розділі прози, що весь є віршем, показують як вірш через `poems` (так «Хвала свині» серед придибенцій). Рядки, надруковані праворуч (підпис і дата під листом), розпізнаються як `[праворуч] …` і на сайті стоять праворуч.

Збірки «Хроніка воєнного дитинства» (1985) у скані немає: її відтворено частково — вірші однойменного циклу з «Передай кодолу!» (2007) і «Присвят і послань» (1983), «Як я Леніна малював» із «Б’ю чолом!» (1978), а «Дитячі кишені» переписано з фото сторінки цього видання (нечитабельне позначено «?»); про це сказано в описі книги.

Оригінали .docx і PDF кладіть у `_source/` — ця папка не потрапляє в репозиторій. Виправлення регістру назв зберігаються в `scripts/import/<книга>.json`. Після імпорту основним джерелом стають `.md`-файли: правте їх, а повторний імпорт (`--force`) затре ручні правки.

## Пошуковики

- Карта сайту створюється автоматично під час збирання: https://wyrax.github.io/mykola-som/sitemap-index.xml. До неї потрапляють усі опубліковані сторінки, крім пошуку, 404 і чернеток.
- Кожна сторінка має канонічну адресу (`<link rel="canonical">`); сторінка 404 позначена `noindex`.
- `robots.txt` для сайту на `wyrax.github.io/mykola-som/` пошуковики не читають (він мав би лежати в корені домену), тож карту сайту треба надіслати вручну: Google Search Console → ресурс «URL-префікс» `https://wyrax.github.io/mykola-som/` → «Файли Sitemap» → `sitemap-index.xml`. Так само в Bing Webmaster Tools.
- `public/googleec3764e8b6a9dded.html` — файл підтвердження права власності в Google Search Console. Не видаляйте його, інакше Google втратить доступ до ресурсу.

## Інше

- Назва сайту, підзаголовок, опис: `src/site.ts`.
- Головна сторінка — книги на часовій лінії за роком видання: `src/components/BookTimeline.astro` (там і чорнильні плями та сліди від кави). Попередні варіанти головної лежать у `src/pages/varianty/` і відкриваються лише за прямою адресою (`/varianty/tekst/` … `/varianty/retro-3/`): посилань на них немає, пошуковики їх не індексують, у карту сайту вони не потрапляють.
- Сторінка «Про автора»: `src/pages/pro-avtora.md`, фото кладіть у `public/`.
- Стилі (шрифт, кольори, світла й темна теми, друк): `src/styles/global.css`.
- Типографіка всіх сторінок: після ініціалів ставиться нерозривний пробіл, тож «О. П. Довженка» не розбивається між рядками. У файлах творів пишіть звичайні пробіли. Це робить `src/middleware.ts` (правило — у `src/lib/typography.ts`).
- Рядок вірша, що не вміщається в ширину екрана, переноситься як у друкованих книжках: перенесена частина стоїть біля правого краю. Такі рядки позначає класом `line--wrapped` скрипт у `src/layouts/Base.astro`, стиль — у `src/styles/global.css`.
